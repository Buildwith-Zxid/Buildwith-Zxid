### The Ecosystem

**SnowBrain** — the intelligence and backend layer. Centralizes reasoning,
context, memory, intent understanding, model routing, and knowledge, so it
can power multiple clients instead of being wired to one UI.

**Snow LLM** — the model and intelligence direction underneath the
ecosystem. Focused on language understanding, reasoning, and contextual
generation — an evolving intelligence layer, not a foundation model built
from scratch.

**Snow Core** — the deterministic execution engine beneath everything
user-facing. Natural-language intent processing, normalization, alias
resolution, entity extraction, context resolution, multi-intent handling —
the reliable bridge between language and action.

**Snow** — the user-facing personal AI assistant. Conversation, voice,
context, reasoning, and system-level automation, built to live across
client platforms rather than as a single website chatbot.

**Snow Cofounder** — an AI-powered workspace for real work. Modular
execution modes and workflows rather than another chat window bolted onto
a model.

**Snow Notebook** — a local-first knowledge workspace. Notes, structured
knowledge, a visual knowledge graph, and AI assistance where it earns its
place — built to function as a knowledge system, not a chat log.
