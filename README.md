## 🚀 What I'm Building

<table>
<tr>
<td width="50%" valign="top">

### 🧠 SnowXAI
An AI technology ecosystem focused on intelligent systems, AI assistants, and software products — the parent platform tying every product together.

</td>
<td width="50%" valign="top">

### ❄️ SnowBrain
The centralized AI backend powering the entire ecosystem. A **thin-client architecture** where every app (Windows, Android, iPhone, Web) handles only UI/UX, while all reasoning happens here — via the Intent Engine, Memory Engine, Context Engine, Model Router, and Knowledge Graph.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🤖 Snow
A personal AI voice assistant built for Windows — calm, dry, non-verbose, and action-oriented (Jarvis-inspired). Purely semantic intent resolution across **English, Hindi, and Hinglish**, with a Python backend, Groq-powered LLM classification, and an AHK execution bridge.

</td>
<td width="50%" valign="top">

### ⚙️ Snow Core
The foundational engine layer beneath Snow — handling intent classification, execution workspaces (Coding, Data, Writing), and the "Publish Button" workflow that turns AI output into real, executable action.

</td>
</tr>
</table>
